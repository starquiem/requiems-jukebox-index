# shitbox radio
an index that i made
## what its about

i made this for fun

its for jukebox mod ( geometry dash mods )

i was bored

add this to your jukebox

## how to use

1. [get geode for your platform](https://geode-sdk.org/)
2. [get the jukebox mod](https://geode-sdk.org/mods/fleym.nongd)
3. go 2 jukebox settings and click index
4. add [this url](https://raw.githubusercontent.com/starquiem/shitbox-radio/refs/heads/main/index.json) to the index
5. click apply
